# 질문 방식

질문은 오류를 막으려고 하는 것이다 — 많이 묻는 게 목적이 아니다.

## 원칙

1. **한 번에 묶어서, 4개 이하.** 하나씩 여러 번 주고받지 않는다.
2. **선택지로.** 열린 질문은 프롬프트 내용(무엇을 찍을지)에만 쓴다.
3. **기본값을 채워 보여준다.** 앱 현재 설정 → 없으면 앱 기본값 → 없으면 용도에 맞는 추천. 사용자는 바꿀 것만 고른다.
4. **이미 분명한 건 묻지 않는다.** 대화, 첨부 파일, 지난 생성 설정, 사용자가 말한 모델·비율.
5. **모드에 따라 필요한 것만.** 입력이 잠그는 값(→ `app-rules.md`)은 묻지 말고 "자동"이라고 알린다.
6. **팀·프로젝트는 묻지 않는다.** 앱에서 고른 것을 확인 카드에 보여주기만.
7. 프롬프트 내용이 애매하면 공식 스킬의 규칙을 따른다 — sd25-pe 는 "여러 해석이 결과를 크게 바꿀 때만 한 번에 묶어서" 묻는다.

## 이미지 (나노바나나)

| 유형 | 알아볼 것 | 질문 예 |
|---|---|---|
| **A. 새로 만들기** | 용도, 모델, 해상도, 비율, 장수 | 용도 `[룩 확인·스토리보드 / 최종 어셋 / 인물 / 제품]` → 모델·해상도는 용도로 추천 · 비율 · 장수 `[1 / 4 / 10]` |
| **B. 레퍼런스로 편집·변형** | 무엇을 유지·바꿀지, 모델, 장수 | 유지할 것 `[얼굴 / 구도 / 색감 / 배경]` · 모델 (편집 정밀도면 GPT 2.5 sunburst 추천) · 장수 |
| **C. 인물 시트·캐릭터** | 몇 컷 구성, 배경, 실사 정도 | 구성 `[얼굴 클로즈업·정면·뒷모습 / 표정 시트 / 전신 턴어라운드]` · 배경 `[회색 / 흰색]` · 장수 |
| **D. 여러 장면 일괄** (콘티 등) | 장면 목록, 통일할 것, 모델·해상도 | 통일할 것 `[인물 / 조명 / 색감]` · 모델·해상도 · 장면당 장수 |

- 카툰·일러스트, 질감 강한 사진 → `gemini-3.1-flash-image` (Higgsfield 의 Nano Banana 2)

## 영상 (시댄스)

순서대로 정하되, 한 번에 묶어서 묻는다.

1. **모델** — 그 프로젝트에서 쓸 수 있는 것 중. 기본 추천은 Seedance 2.5. 4K 가 필요하면 2.0 (프로젝트 권한 필요), 빠른 시안이면 2.5 초안(Draft) 또는 2.0 Fast.
2. **모드** — 첨부로 거의 정해진다: 이미지 1장 → 첫 프레임, 2장(시작·끝) → 첫·끝 프레임, 여러 장·영상·오디오 → 레퍼런스, 기존 영상 고치기 → 편집.
3. **모드별로 필요한 것만**

   | 모드 | 물을 것 | 묻지 않을 것 (자동) |
   |---|---|---|
   | 텍스트→영상 | 비율, 길이, 해상도, 개수, 오디오 | — |
   | 첫 프레임 / 첫·끝 프레임 | 길이, 해상도, 개수, 오디오 | 비율 (이미지 기준, 2.5) |
   | 레퍼런스→영상 | 레퍼런스별 역할(누가 누구인지), 비율, 길이, 해상도, 개수, 오디오 | — |
   | 영상 편집 | 무엇을 바꿀지, 해상도, 개수 | 비율·길이 (입력 영상 기준, 2.5) |
   | 영상 연장 | 앞/뒤, 늘릴 길이, 해상도, 개수 | 비율 (입력 영상 기준) |

4. **길이·해상도는 모델 범위 안에서만** 선택지로 낸다 (`app-rules.md`). 2.5 는 초안(Draft)이 기본 — 최종본인지 묻는다.
5. **오디오 ↔ 마지막 프레임**: 다음 컷으로 이어 붙일 마지막 프레임이 필요하다고 하면 오디오는 꺼진다고 알린다.

### 질문 예 — "이 콘티로 비 오는 골목 영상"

```
지금 프로젝트(앱에서 고른 ○○) 기준으로 이렇게 갈게요. 바꿀 것만 골라 주세요.
1) 모델: [Seedance 2.5 (추천)] [2.0] [2.0 Fast]
2) 길이: [5초] [10초 (추천)] [15초]
3) 화질: [초안 720p — 먼저 확인] [1080p 최종]
4) 개수: [1] [2] [3]
비율은 콘티 이미지에 맞춰 자동, 오디오는 켭니다.
```
